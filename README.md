
# StayEase – Hotel Booking Portal

A full-stack hotel booking application with coupon management.

## Technology Stack

- Frontend: React.js
- Backend: Node.js and Express.js
- Database: MySQL
- API Testing: Postman
- Automated Testing: Jest and Supertest

## Main Modules

### Customer Portal
- Browse and search hotels
- Check room availability
- Book hotel rooms
- Apply discount coupons
- Retrieve and cancel bookings

### Admin Dashboard
- Admin login
- Create and manage coupons
- Activate and deactivate coupons
- View coupon usage statistics

## Project Structure

- frontend/ – React application
- backend/ – Node.js and Express application
- database/ – Database scripts and migrations
- docs/ – Project design documentation
- screenshots/ – Application screenshots
